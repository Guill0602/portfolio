# Guillermo V. C. Sango Portfolio

React portfolio built with Vite.

## Run Locally

```powershell
npm install
npm run dev
```

## Build

```powershell
npm run build
```

## Push To GitHub

Create a new GitHub repository, then run these commands from this project folder:

```powershell
git init
git branch -M main
git add .
git commit -m "Initial portfolio"
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
git push -u origin main
```

## Host On GitHub Pages

This repo can be hosted by publishing the built `dist` folder to a `gh-pages` branch.

Your site URL will be:

```text
https://YOUR_USERNAME.github.io/YOUR_REPOSITORY/
```

If the repository is named `YOUR_USERNAME.github.io`, the URL will be:

```text
https://YOUR_USERNAME.github.io/
```
